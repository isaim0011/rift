## 2. High-Value SEO Backlink Targets

1. **Awesome Rust**:
   - Submit PR to `rust-unofficial/awesome-rust` under **Network Programming** / **Discord API**.
2. **Awesome Discord**:
   - Submit PR to `discord/awesome-discord` under **Libraries**.
3. **Lib.rs**:
   - Auto-indexes from crates.io (`rift-discord`).
4. **Docs.rs**:
   - Auto-generates rustdoc documentation at `https://docs.rs/rift-discord`.
5. **OpenAPI Directory**:
   - Submit Rift coverage verification methodology to API aggregators.
6. **Discord Developers Official Server**:
   - Post in `#community-resources` and `#library-development`.
