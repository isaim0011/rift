Aegis Sentinel Privacy Policy

Effective Date: November 2, 2026 • Application ID: 1366672684866076813

This Privacy Policy outlines how Aegis Sentinel ("the Application", "we", "us") collects, processes, and protects information when added to a Discord server or interacting with Discord users.

Summary: Aegis Sentinel collects only the minimal technical data required to safeguard your Discord server against raids and unauthorized mass administrative actions. We never sell your data, we never profile users for advertising, and we do not store message contents permanently.

1. Information We Collect

To perform automated anti-nuke, anti-raid, and security functions, Aegis Sentinel processes the following Discord data:

  • Discord Snowflake Identifiers: Unique 64-bit numerical IDs for Guilds (servers), Channels, Roles, and Users to maintain server-specific security configurations and permission policies.
  • Audit Log Metadata: Administrative action counts (e.g. channel creations, deletions, role modifications, member kicks/bans) within rolling rate-limit windows to detect rogue account behavior.
  • Server Structure Snapshots (Optional): Server configuration data (channel names, role hierarchies, permission overwrites) saved only when an administrator explicitly requests a security snapshot for disaster recovery.
  • Ephemeral Message Inspection: Real-time scanning of message content for known phishing domains, malicious invite links, or token loggers. Content is evaluated in volatile memory and discarded immediately; message content is never written to disk or database storage.

2. How We Use the Information

Collected data is used strictly for:

  • Detecting and neutralizing automated raid attacks and compromised administrative tokens.
  • Enforcing server-configured rate-limits on administrative operations.
  • Restoring server structure upon verified administrator disaster-recovery requests.
  • Maintaining command execution rate limits to prevent denial-of-service disruptions.

3. Data Sharing & Third Parties

We do not sell, rent, monetize, or share your data with advertisers or third parties. Data is never transferred outside of our secure bot infrastructure except as necessary to communicate directly with Discord's official Gateway and REST APIs.

4. Data Retention & Storage Security

  • Volatile Caches: Anti-spam and anti-nuke counters reside strictly in temporary RAM caches and automatically expire within minutes.
  • Incident Logs: Audit event history logs are retained for a maximum of 30 days before being automatically purged.
  • Server Removal: If Aegis Sentinel is kicked or removed from your Discord server, all active server caches associated with that server ID are promptly scheduled for deletion.

5. User Rights & Data Deletion (Right to Erasure)

Under GDPR, CCPA, and Discord developer standards, server owners and users have the right to request deletion of any stored data associated with their Discord Guild or User ID. To request complete data erasure, simply submit a request with your Guild ID or User ID to i.s41m0011@gmail.com or open an issue on our GitHub repository. Requests are fulfilled within 7 business days.

6. Changes to this Policy

We may update this Privacy Policy from time to time. Any material changes will be reflected with an updated effective date on this page.

7. Contact

For questions or data deletion requests, contact the developer at i.s41m0011@gmail.com or visit github.com/isaim0011/rift.
